# BeBetter

## Projektziel

BeBetter ist eine Webanwendung für Fitness und Ernährung. Benutzer können ihre Trainingseinheiten dokumentieren, ihre Fortschritte verfolgen und ihre Ernährung planen.

## Projektstruktur

* `backend/` – Java-/Spring-Boot-Projekt für die Backend-Logik und API
* `frontend/` – React-/Vite-Projekt für die Benutzeroberfläche
* `database/` – Dokumentation zur Datenbank
* `docs/` – Setup-Anleitung und Projektvereinbarungen

## Technologien

* Backend: Java und Spring Boot
* Frontend: React und Vite
* Versionsverwaltung: Git
